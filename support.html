Getting started

My external drive doesn't appear when I pick a destination

In the Files picker, tap Browse at the bottom right — twice. The first tap moves you up a level, the second reveals the full list of locations, including connected drives. This is how the iOS file picker behaves generally, not something specific to this app.

If the drive still isn't listed, check it appears in the Files app itself. A drive that needs more power than the device supplies may need a powered hub.

Which files get copied?

Common photo formats — RAW from most manufacturers, plus JPEG, HEIC, TIFF, PNG and WebP. The Supported Formats screen in the app lists them all. XMP sidecars are carried across alongside the images they belong to.

Supported RAW formats are determined by iOS rather than by the app, so a very new camera may need an iOS update before its files can be previewed.

Backing up

What happens if I unplug the card, or the app closes mid-backup?

Nothing already copied is lost. Files are written under a temporary name and only renamed once every byte has landed, so a half-written file never appears under a real filename.

The next time you open the app it will offer to resume. Resuming skips everything already at the destination — which is fast — and copies only what's missing.

Can I stop a backup safely?

Yes. The file being copied finishes first, so nothing is left partial. Files copied so far stay where they are, and running the backup again later picks up the rest.

Why did it say "Backup Interrupted"?

Some files didn't make it across — most often because the card or drive was disconnected part-way. Tap through to see which. Running the backup again re-copies just those.

Can a backup keep running while I use another app?

By default, iOS pauses the app shortly after you switch away, and the backup continues when you come back. To keep it running instead, turn on Keep Running in Background in Settings, then close and reopen the app. On iOS 26 or later the backup's progress then shows on your Lock Screen. It can use more battery, so it's off unless you need it.

Verifying

Quick or Full — which should I use?

Quick compares file sizes, which is fast and catches truncated or missing files. Full computes a SHA-256 hash of every byte of both copies, which is slower but the only way to catch a file that is the right size and still wrong.

Before formatting a card, Full is the one worth the wait.

What does the Verified badge mean?

That file passed a backup check: the copy at the destination matched the original. The badge appears on thumbnails in Browse and in each photo's info panel, on both the original and the copy. If a file later fails a check, it loses the badge.

Some files didn't match. What now?

They're kept as a repair list, shown as a banner in Backup, and it survives closing the app. Tap Repair and only those files are copied again and re-checked by hash.

If the same file fails twice, treat that as a hardware warning rather than a glitch. A file that won't copy correctly on two attempts usually means the card or the drive is failing — try a different drive before trusting the backup.

Rating and keywords

Where do my stars and keywords go?

Into XMP sidecar files saved beside each photo, in the standard format Lightroom, Capture One and Bridge read. Import the folder later and your work is already there.

If a photo already has a sidecar from another application, PhotoBackup edits only the rating, label and keyword fields, leaving develop settings and history untouched.

Can I use my own keyword list?

Yes. In Settings, under Keywords, tap Save Sample Keywords File to put a starter file in Files. It's plain text, one keyword per line, with lines starting # ignored so you can leave yourself notes. Edit it in any text editor, then load it back from the same screen.

What is Combined JPG + RAW view?

When a shot exists as both a RAW and a JPEG with the same filename, the pair is shown as one item instead of two. Ratings and keywords applied to it are written to both files.

Appearance and accessibility

How do I switch between Light and Dark?

In Settings, under Appearance, choose Light, Dark or System. System follows your device's own setting. The full-screen photo viewer always stays dark, so photos are judged against black.

Does it work with VoiceOver and larger text?

Yes. Every button is labelled, each row of stars is a single control you can swipe up or down to change, and text and icons follow the text size set in your device's Settings.

Is there a quicker way to rate in Browse?

Long-press a thumbnail for Pick, Reject, Share and Info. Select is in the same menu, for choosing several photos at once.

Purchases

What's included in the free trial?

Everything, for the length of the trial. After it ends, backup, verification, rating, keywording and XMP generation need the full version, and Browse shows the first 50 photos of a folder. Viewing, sharing and deleting your own photos stay free — your files are never held hostage.

I bought it but it isn't unlocked

Settings → Restore Purchases. If it reports nothing found, the purchase is most likely on a different Apple ID — sign in with that one and try again. The unlock is a one-time purchase tied to your Apple ID, so it carries to your other devices and to a reinstall.
